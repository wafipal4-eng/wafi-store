# ✨ WAFI Premium Store

منصة متجر إلكتروني فاخرة ومتعددة اللغات  
مبنية بـ **Next.js 15 + Supabase + Tailwind CSS**

## المميزات
- واجهة متجر أنيقة مع دعم كامل للعربية (RTL)
- لوحة تحكم احترافية لإدارة المنتجات والطلبات
- سلة شراء ذكية وتجربة مستخدم سلسة
- دعم متعدد اللغات (عربي / إنجليزي)
- تحليلات ومبيعات متقدمة
- تصميم قابل للتخصيص بالكامل (ألوان، شعار، محتوى)
- جاهز للنشر على Vercel

## التثبيت والتشغيل

```bash
# 1. تثبيت الحزم
npm install

# 2. إنشاء ملف البيئة
cp .env.example .env.local

# 3. تشغيل المشروع
npm run dev
```

افتح المتصفح على: http://localhost:3000

## الإعدادات المهمة
عدّل الإعدادات من الملف:
`src/app/lib/constants.ts`

- اسم المتجر
- الألوان
- الشعار
- رقم الواتساب
- معرف المتجر (store_id)

## النشر على Vercel
1. ارفع المشروع على GitHub
2. استورد المشروع في Vercel
3. أضف المتغيرات من `.env.example`
4. اضغط Deploy
